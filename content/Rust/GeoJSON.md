#### Geometry Primitives
| Data Type  | Example                                                                                                                                                                                                                                      | Notes                                                                                                                                                                        |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Point      | {<br>    "type": "Point", <br>    "coordinates": [30.0, 10.0]<br>}                                                                                                                                                                           | format includes type<br>and two coordinates<br>(latitude/longitude)                                                                                                          |
| LineString | {<br>    "type": "LineString", <br>    "coordinates": [<br>        [30.0, 10.0],<br>        [10.0, 30.0],<br>        [40.0, 40.0]<br>    ]<br>}                                                                                              | format includes type<br>and at least two<br>coordinates                                                                                                                      |
| Polygon    | {<br>    "type": "Polygon", <br>    "coordinates": [<br>        [<br>            [30.0, 10.0],<br>            [40.0, 40.0],<br>            [20.0, 40.0],<br>            [10.0, 20.0],<br>            [30.0, 10.0]<br>        ]<br>    ]<br>} | format includes type<br>and at least three<br>coordinates. Critically,<br>the first and last <br>coordinate must be<br>identical (point 1, <br>point 2, point 3, point<br>4) |
